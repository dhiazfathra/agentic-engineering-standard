- 2026-09-23 [project] Two sessions edited this working tree at once. Evidence: `README.md`, `tests/run.sh`, and the hook gained uncommitted edits from another session while this one worked on the same files. On 2026-09-24 the reverse happened: a background worker sharing the tree committed this session's uncommitted lesson lines inside its unrelated `fix(rewind)` commit `6052e6e`. Do instead: run `git status` at session start. If there are foreign changes, use a git worktree, or stage only your own hunks. Commit your own edits before a background agent in the same tree can commit, or give that agent `isolation: worktree`.
- 2026-09-23 [general] Claude Code loads `.claude/agents/` at session start only. Evidence: the session that added `worker` and `chore` got "Agent type 'worker' not found" while its own opus-delegates hook blocked every other route. Do instead: land a new agent together with the gate that needs it, then restart the session before relying on either.
- 2026-09-23 [general] A gate that sends one-line commands to a subagent costs more than it saves. Evidence: "commit push" on Opus took 4 min and 2 subagent starts; the same command by hand took under 1 s (docs/reports/2026-09-23-slow-commit-push.md). Do instead: delegate only work bigger than a subagent start, and do exactly what was asked before adding scope.
- 2026-09-23 [project] Firstmate's `fm-ensure-agents-md.sh .` replaces the `CLAUDE.md -> AGENTS.md` symlink with a regular file holding an `@AGENTS.md` import. Evidence: `git status` showed `T CLAUDE.md` right after the script ran; it happened again on 2026-09-24, leaving a 90-byte file. Do instead: after running it, check `ls -la CLAUDE.md` and restore the symlink with `ln -sf AGENTS.md CLAUDE.md`; the script needs fixing to leave symlinks alone.
- 2026-09-24 [project] The root Stop hook counts only `^learning/`, so a root session that updates an example's `examples/<name>/learning/` still gets "Files changed but learning/ is untouched". Evidence: the viewer session was nudged three times after committing `examples/rewind/learning/` changes. Do instead: record the example's lessons in its own `learning/`, and teach `learn-nudge.sh` to accept a nested `learning/` (with a `tests/run.sh` case) in a separate change.
- 2026-09-24 [general] The no-mistakes `pr` step overwrites an existing PR description instead of adding to it. Evidence: PR #4 went from a 26-line hand-written body to a 243-line generated one after `no-mistakes axi run --yes`, even though the `--intent` said to append. Do instead: before running no-mistakes on a branch that already has a PR, save the body with `gh pr view <n> --json body -q .body`. After the `pr` step, restore that body and append the generated text below it with `gh pr edit <n> --body-file`. Check it again after the run ends, because any later push can overwrite it.
- 2026-09-25 [general] A no-mistakes review fix commit can pass the gate while failing the project's own checks. Evidence: `4c64b97` passed with a 62 ms lint step, yet `bun run --filter web lint` failed on a ref written during render, branch coverage fell to 98.98% under a 100% threshold, and a queued save that failed after the first succeeded no longer rolled back. It was reverted in `9da03aa`. Do instead: after every run that adds commits, run the project's real lint and test commands on the new head before trusting `checks-passed`. When reverting, state in `--intent` what must not come back.
- 2026-09-25 [general] A finished background agent can be resumed from outside the session and push to the shared branch. Evidence: three times on PR #4 a done agent was sent new instructions it did not get from this session; the third time it pushed `3ebeea9` with a `Co-Authored-By` trailer and evidence describing reverted code, which needed a force-push to remove. Do instead: tell background agents never to commit or push, collect only raw output from them, and after every agent notification run `git fetch origin`, then check `git log origin/<branch>` for foreign commits.
- 2026-09-25 [project] A root session loads the root `.claude/hooks/opus-delegates.sh` (symlinked to the agnostic template), not the example's copy, so deleting `examples/<name>/.claude/hooks/opus-delegates.sh` does not unblock it. The hook also assumes an Agent tool, which some sessions lack, leaving Opus unable to write code at all. Evidence: after `rm examples/rewind/.claude/hooks/opus-delegates.sh`, a Write to a scratchpad `.ts` file still failed with "Only Markdown edits (plans, specs, docs) are allowed on Opus", and ToolSearch found no Agent tool. Do instead: open the example directory as the workspace for implementation work, or switch to Sonnet; check that the Agent tool exists before planning to delegate.
- 2026-09-25 [general] A `worker` subagent told to "commit and push" committed but did not push, and reported its chunk done while half of it was still open. Evidence: chunk 2 worker returned "2 commits, no push" and listed migration, login page, endpoints and ADR as not done. Do instead: after each worker, run `git log origin/main..HEAD` and push leftovers; give workers one chunk small enough to finish in one run.
