# Extension parity audit (EXT)

Design: `Rewind.dc.html` in-page mock (`ext` = null | home | drafts | settings; `extMenu`, `shotOpen`, `recOpen`, `micOpen`, `delay`, `rec`, `editor`, `destOpen`). Popup crops made by a scratch script, `-design` half left, `-app` half right in compare images.
App: `apps/extension` built (`bun run build`, `.output/chrome-mv3`), loaded unpacked in a Playwright persistent Chromium, popup.html at 390px wide, editor.html?id=<seeded IndexedDB draft>. Web-app origin is not needed for these views (appUrl defaults to https://rewind-ecru.vercel.app, editable in popup Settings). Not compared: the recorder bar and countdown (recorder.html needs a real tabId from the background message, standalone it shows "No tab with id: 0"), and the in-page capture overlays (area selector). Design frames for them are kept for reference only.

Manifest (`wxt.config.ts`): permissions `storage`, `tabs`, `alarms`, `unlimitedStorage`, `tabCapture` (chrome only); host_permissions `<all_urls>`; commands Alt+Shift+S (screenshot), Alt+Shift+R (save-replay).
Sign-in: the popup has NO sign-in / signed-in / sign-out UI, and no auth code exists in entrypoints/lib (grep for sign/login: none). The design mock has none either (no sign-in state in `ext`). The e2e logs in via the web app cookie (ADR-0003), so upload relies on the user's web session. Required-flow gap: nothing in the popup tells a signed-out user to sign in.
